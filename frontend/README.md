# Круг — прототип интерфейса

Многостраничный frontend финансового приложения «Круг» на чистом HTML/CSS/JS, подключённый к FastAPI backend через `api.js`.

## Структура

```
index.html          — Главная
finances.html        — Финансы (обзор)
operations.html       — Операции
balances.html         — Балансы
analytics.html        — Аналитика
debts.html            — Задолженности
members.html          — Участники
ai-assistant.html     — AI-помощник
settings.html         — Настройки
style.css             — общие стили всех страниц
script.js             — ripple-эффект и микро-анимации кликов
```

## Как запустить

Запустите FastAPI из корня проекта и откройте `http://localhost:8000/demo`. Прямое открытие HTML-файла не используется, потому что данные загружаются из backend API.

## Публикация на GitHub Pages

1. Создайте репозиторий и загрузите в него все файлы из этой папки.
2. В настройках репозитория откройте `Settings → Pages`.
3. В качестве источника (`Source`) выберите ветку `main` и папку `/root`.
4. Через минуту сайт будет доступен по адресу `https://<ваш-логин>.github.io/<название-репозитория>/`.

## Технологии

Чистый HTML5, CSS (переменные, grid, flexbox) и vanilla JS. Иконки — инлайновые SVG, без внешних библиотек и шрифтов.
