# 💰 Круг — умный учёт общих финансов

**Демо:** (http://45.146.164.213) • **API:** (http://45.146.164.213/docs)

> Веб-приложение для совместного учёта финансов в квартире, семье или компании друзей. Создайте группу, добавляйте расходы — а «Круг» автоматически рассчитает, кто кому должен, и предложит минимальное количество переводов для полного расчёта.

---

## 🎯 Проблема

При совместном проживании финансовые данные разбросаны по чатам, заметкам и таблицам. Невозможно быстро ответить:
- ❓ Кто сколько заплатил?
- ❓ Как разделить конкретный расход?
- ❓ Кто кому должен?
- ❓ Какие долги уже погашены?

**«Круг»** решает эту проблему, храня все операции в одном месте и автоматически рассчитывая балансы.

---

## ✨ Ключевые возможности

### 👥 Группы и участники
- Создание группы за 15 секунд
- Приглашение по ссылке
- Автоматическое восстановление сессии

### 💸 Умные операции
- **3 способа разделения:** поровну, вручную, по процентам
- Точный расчёт до копейки (проверено тестами)
- Категории расходов + пользовательские

### ⚖️ Балансы и долги
- Автоматический расчёт чистого баланса
- Оптимизированные переводы (минимальное количество)
- Прямые долги и история погашений

### 📊 Аналитика
- Расходы по категориям и месяцам
- Прогноз бюджета до конца месяца
- Сравнение периодов
- AI-моделирование изменений

### 🤖 Уникальные фишки
- **AI-помощник** на базе DeepSeek — спросите «Сколько мы потратили на еду в этом месяце?»
- **Распознавание QR-кодов чеков** — сфотографируйте чек, и расход добавится сам
- Тёмная/светлая тема

## 🛠 Технологический стек

| Категория | Технологии |
|-----------|------------|
| **Backend** | Python 3.12, FastAPI, Pydantic 2 |
| **База данных** | PostgreSQL, Supabase |
| **AI** | DeepSeek (OpenAI-compatible API), tool calling |
| **Обработка чеков** | OpenCV, Pillow, pillow-heif |
| **Frontend** | HTML5, CSS3, Vanilla JavaScript (без фреймворков) |
| **Инфраструктура** | Docker, Docker Compose, GitHub Actions, GHCR |
| **Тестирование** | Pytest (100% покрытие core-логики) |
